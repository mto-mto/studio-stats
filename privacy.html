Privacy policy

Studio Stats · effective 26 November 2026

The app

Studio Stats is a personal command-line tool that the owner of a YouTube channel runs on their own computer to read that channel's analytics. It has no server, no user accounts and no other users.

What it reads

With the permission the channel owner grants when signing in with Google, and only for the owner's own channel, it reads:

  • YouTube Analytics and YouTube Reporting data: per-video views, watch time, average view duration, thumbnail impressions and click-through rate, audience retention, traffic sources, likes and subscriber changes. These are totals and averages that YouTube prepares; they don't identify individual viewers.
  • The channel's list of videos from the YouTube Data API: titles, durations, publish dates and privacy status.

It doesn't read email, contacts, files or any other Google data, and it can't change anything on the channel.

How the data is used

Only to produce reports for the channel owner about their own videos.

Where the data is kept

On the owner's computer: the downloaded reports, and the sign-in token in a local configuration file that never leaves that computer. The app doesn't send the data anywhere else.

Sharing

The data isn't sold, used for advertising, or shared with anyone. Studio Stats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting it

The data stays until the owner deletes the files. Access can be revoked at any time on Google's security settings page; after that the app can read nothing more.

YouTube API Services

Studio Stats uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

This website

These pages have no cookies, analytics or tracking. They're hosted on GitHub Pages, which may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Changes and contact

Changes to this policy will be posted on this page with a new date. Questions: open an issue in this site's repository.
